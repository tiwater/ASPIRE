# 用户确认后的容量、接触力与倾倒初值

容量目标明确为 **杯子容量的 80%**。用户同意先用几何体积估算容量，用水密度近似换算质量；
空壶质量采用用户提供的 **396 g**。没有假装得到新的称量或容积实测。

## 可重算的初值

杯子按圆锥台内腔计算：`V = π h (r底² + r底 r口 + r口²) / 3`。
从照片模型的外半径扣除壁厚，从高度扣除杯底厚度；内腔底半径取杯底上表面处的线性插值。
杯口外径 70 mm、底外径 50 mm、高 80 mm、壁/底厚 1 mm 均仍是照片/建模估计。
水密度暂取 `1000 kg/m³`，重力取 `9.80665 m/s²`。

| 参数 | 当前结果 | 依据 |
|---|---:|---|
| 杯内腔容量 | 约 212 ml | 圆锥台近似，非实测 |
| 80% 目标 | 约 169 ml / 169 g 水 | 用户确认容量比例 |
| 壶容量 | 约 1.57 L | 现有壶模型内腔近似，非实测额定容量 |
| 满壶参考总质量 | 约 1.966 kg | 空壶 396 g + 满内腔水 |
| 弹簧参考力 | 约 9.64 N | 满壶总重的一半 |
| 杯架参考拔出力 | 约 4.15 N | 两满杯水的重力，不含杯皮重量 |

“满壶”在这里包含壶自身重量；“两杯水”指两满杯，不是两杯各八成。
尺寸变化时自动重算，避免把上述数字复制到多处后失去一致性。

```bash
PYTHONPATH=src .venv-libero/bin/python -m cap_harness.realman estimate
```

## 力与仿真参数的区别

弹簧采用 `F(x) = F预载 + k x`。暂取零预载，沿用未实测的 8 mm 参考压缩量，
使 `F(8 mm) ≈ 9.64 N`，得到 `k ≈ 1205 N/m`。这不表示全行程恒为 9.64 N，
也不表示咖啡壶的水平退出阻力等于这个数；还受接触斜面、摩擦及壶盖形状影响。
构建模型时由力初值推导刚度，输出 `parameter_estimates.json`。

杯架的 4.15 N 是希望后续辨识的拔出力参考。现有模型中的三触点刚度/摩擦保持为名义稳定参数，
没有声称它们能精确产生 4.15 N。要匹配拔出力，需要加入抓杯路径、杯沿和纸杯形变并做拉拔测量。
它也不是夹爪夹紧力或机器人碰撞阈值。

模型总空壶质量已修正为恰好 396 g（壶嘴质量计入总额）。当前不模拟水体，
用于弹簧估算的“满壶质量”不会自动加到仿真壶上；以后验证负载时需明确初始水量并加入等效质量/惯量。
这些参数不自动变成真机执行限制，`hardware_force_limit_qualified` 仍为 false。

## 倾倒几何初值

按用户要求暂不做详细流体仿真，先实现可测试的几何/速度检查：

- 壶嘴目标点投影落在杯口内，距内杯沿保留 5 mm 余量。
- 默认壶嘴高于杯沿 10–25 mm。第一版先靠近杯口，不强制插入纸杯。
- 初始倾倒角速度上限候选为 5°/s；这只是待验证的保守调试值，尚未接入真机速度控制器。
- 使用杯子局部坐标判断，随杯姿态更新目标；完整壶体、杯壁、双臂碰撞需要另外检查。

`pour_envelope` 只检查传入的壶嘴位置与角速度，不证明不会洒、不证明壶体无碰撞、
不证明实际倾倒量达到了 169 ml。即便不做流体仿真，真机仍需称重、液位或经实测的流量反馈停止倾倒。

标定配合流程见 [calibration.md](calibration.md)。
